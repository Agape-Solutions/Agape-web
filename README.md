## 📋 Sobre o Projeto

O **Kineo** é uma solução desenvolvida para facilitar o acompanhamento fisioterapêutico de pacientes em ambiente hospitalar.

O projeto tem como principal objetivo centralizar informações que atualmente são distribuídas em diferentes planilhas, reduzindo processos manuais e facilitando a busca, acompanhamento e análise dos dados.

A plataforma busca proporcionar uma visão integrada do paciente durante sua passagem pelos diferentes setores do hospital.

---

## 🎯 Objetivo

* Centralizar os dados dos pacientes;
* Unificar informações de diferentes setores e meses;
* Facilitar a busca ativa;
* Acompanhar a evolução dos pacientes;
* Automatizar indicadores;
* Reduzir processos manuais;
* Facilitar a análise dos dados.

---

## 💡 Principais Funcionalidades

* 👤 Cadastro e acompanhamento de pacientes;
* 🔎 Busca ativa;
* 🏥 Acompanhamento por setores;
* 📋 Histórico do paciente;
* 🏃 Protocolo de mobilização;
* 📊 Indicadores e dashboards.

## 📌 Escopo

O projeto contempla o desenvolvimento de uma solução para gestão e acompanhamento fisioterapêutico hospitalar, desde a centralização e tratamento dos dados até a disponibilização de indicadores e ferramentas de acompanhamento.

A entrega do projeto está prevista para ocorrer após **junho de 2027**.

O desenvolvimento contempla a criação da solução, não incluindo custos relacionados à aquisição de equipamentos, infraestrutura, serviços externos ou implementação.
